# EFA Institute of Computer Academy (website)

This repository contains a simple, responsive brochure website for:
EFA Institute of Computer Academy — Sillanwali, Sargodha, Pakistan.

Preview locally
1. Open `website/index.html` directly in a browser (basic preview).
2. Or run a static server from the `website` directory:
   - Python 3: `python -m http.server 8000`
   - Then open http://localhost:8000

What’s included
- Mobile-first plain HTML/CSS/vanilla JS (no frameworks).
- Responsive layout, accessible mobile navigation, WhatsApp/tel CTAs.
- Placeholder logo and favicon (to be replaced with your real assets).

Notes
- No backend, payment, maps, frameworks, or fake content are included.
- Next steps (after you review): add course pages, contact form, and optional deployment.
