# Row Level Security (RLS) plan for EFA Institute of Computer Academy

This folder contains guidance and placeholder SQL for implementing RLS policies in Supabase/Postgres.

Important:
- Do NOT apply open permissive policies. Implement least-privilege policies and test them in a staging environment.
- The SQL files here are skeletons and examples only. Each policy must be reviewed and tested.

Example policy skeletons and recommended approach are documented here for later implementation.
